# ECM Lite

ECM Lite is a full-stack Enterprise Content Management (ECM) application built using React, Node.js, Express.js, and PostgreSQL.

## Tech Stack

- React.js
- Node.js
- Express.js
- PostgreSQL
- Git & GitHub

## Features

- User Login
- Dashboard (Planned)
- Document Upload (Planned)
- Document Search (Planned)
- Document Viewer (Planned)
- Role-Based Access (Planned)
